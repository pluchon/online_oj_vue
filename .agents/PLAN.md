## 目标

不再加复杂功能，只把一个 OJ 该有的几个基础功能补齐：

1. **题目标签**：标签由出题人维护，不再按关键词推断；题库可以按标签和做题状态筛选。
2. **题解**：每道题一篇官方题解，管理员可以用 AI 生成草稿，学员在做题页查看。
3. **提交管理与重判**：管理员能查看所有提交；修改用例后可以对某道题重判。
4. **数据概览**：管理端首页展示提交量、通过率、活跃用户、难题等概况。
5. **AI 功能再加一个（待定，二选一）**：赛后 AI 复盘，或薄弱标签练习推荐。

## 明确不做

- 多语言判题（C++ / Python）：每道题的 main 函数和代码模板都按 Java 写，支持多语言需要为每题维护多套，出题和 AI 生成用例也要跟着改，投入最大。
- 讨论区 / 评论：要连带做内容审核、通知、举报和 @，维护成本高。
- Rating 积分、全站排行榜、题单。
- 题目批量导入导出。
